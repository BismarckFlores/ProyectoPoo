Flujo principal

Del registro al resultado en cuatro pasos.

01

Registrar evaluado

Se capturan datos basicos como nombre, apellidos, sexo, estudios y fecha de nacimiento.

02

Crear aplicacion

El backend asigna las formas del examen usando la configuracion activa definida en el panel.

03

Responder items

La web muestra opciones sin revelar respuestas correctas y prepara el envio al API.

04

Consultar resultado

El sistema calcula puntuaciones directas, tipicas e interpretacion del rendimiento.

Arquitectura

Frontend simple, API separada y datos persistentes.

El proyecto mantiene responsabilidades separadas: Bootstrap para la interfaz, TypeScript con Express para los endpoints y PostgreSQL para almacenar evaluados, aplicaciones, respuestas y resultados.
